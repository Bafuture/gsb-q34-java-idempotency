## 任务提示词

以下为本题完整的 User Prompt 原文，两次执行必须使用完全相同的文本。

对外接口经常被上游重复调用，同一个请求送进来两次，业务就被执行了两次。请从零实现一个幂等控制组件：仓库现在只有一个空的 Maven 工程，依赖只有 JUnit 5 与 AssertJ。要求：1) 幂等键：由调用方显式传入，组件支持配置去重窗口，窗口内同一键视为重复；2) 并发合流：同一幂等键的并发请求只允许一个真正执行业务逻辑，其余请求等待并复用第一次的结果；需用多线程测试证明业务逻辑只被执行了一次；3) 结果缓存：执行结果在窗口内可重复返回，异常结果的处理策略可配置（缓存异常或允许重试）；4) 执行中断：首次执行过程中线程被中断或超时，等待方必须拿到明确结果，不得永久阻塞；5) 存储抽象：提供存储 SPI 与内存实现（供单机测试），并说明如何替换为外部存储；6) 统计：命中次数、未命中次数、合流等待次数、超时次数；7) `mvn -q verify` 跑通，覆盖串行重复、并发合流、窗口过期后可再次执行、异常结果策略、等待超时五类场景；8) README 说明并发合流的实现方式与边界。
